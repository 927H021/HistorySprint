# HistorySprint

Application d'histoire en mode sprint : un événement s'affiche, tu tapes son année avant la fin du temps.
Même univers et mêmes écrans que [MathSprint](https://927H021.github.io/mathsprint/) : séries, météo, calendrier, statut Gold, défi du jour sur tes points faibles, mode inversé (retrouver l'événement à partir de l'année).

- Application web installable (PWA), fonctionne hors ligne.
- Données enregistrées uniquement sur l'appareil.

## Installer
- **iPhone (Safari)** : Partager → *Sur l'écran d'accueil*.
- **Android (Chrome)** : menu ⋮ → *Installer l'application*.

## Mise à jour
Après une modification, changer `CACHE_VERSION` dans `sw.js`, puis pousser sur `main`.
